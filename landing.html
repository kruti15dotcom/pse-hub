Features

Everything your team needs

Built for Proactive Services Engineering — no extra servers, no extra logins.

Organized by Customer

Resources are grouped by customer realm — Trend Review, QBR, Implementation — so you always find what you need instantly.

One-Click Upload

Upload any file directly from the extension. It's automatically stored in the team's Google Shared Drive — no manual folder navigation needed.

Shared Across the Team

Every team member sees all uploaded documents. Uploader name and timestamp are shown on every card — full visibility, no silos.

Uploader-Only Delete

Only the person who uploaded a file can delete it. This keeps the shared space clean without giving everyone full edit rights.

Live Realm Sync

Customer list stays automatically in sync with the PROM Live Sheet — new accounts appear without any manual updates to the app.

PSE Resources Tab

A separate admin-protected section for team-wide resources — training docs, quick links, and internal guides — not tied to any customer.

How It Works

Simple upload flow

From install to your first uploaded document in under 3 minutes.

1

Install the Extension

Download the ZIP, go to chrome://extensions, enable Developer Mode, and load the unpacked folder. Done in under a minute.

2

Sign In Automatically

The app uses your existing Chrome Salesforce account — no separate login needed. It identifies you automatically on first open.

3

Browse by Customer Realm

Click the Customer Realms tab, search for your account, and pick a folder like Trend Review or QBR.

4

Upload or Add a Link

Click + Add, choose a file from your machine (or paste a URL), fill in the title, and hit Save. The file lands in the team's Google Shared Drive automatically.

5

Your Team Sees It Instantly

All team members see the new document the next time they open the extension — no refresh, no manual sharing needed.

Get Started

Install in 4 steps

No app store needed. Load it directly in Chrome as an unpacked extension.

1

Download the ZIP

Click the button below to download the latest extension ZIP file.

2

Extract the ZIP

Unzip the file. You'll get a folder called PSELearningHub-Extension.

3

Open Chrome Extensions

In Chrome, go to chrome://extensions and turn on Developer mode (top-right toggle).

4

Load the Folder

Click Load unpacked and select the extracted PSELearningHub-Extension folder.
