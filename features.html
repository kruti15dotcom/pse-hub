Features

Everything your team needs

Built specifically for Proactive Services Engineering — no extra servers, no extra logins.

Organized by Customer Realm

Resources are grouped by customer account and sub-folder — so you always know exactly where to look.

  • Folders: Trend Review, QBR, Implementation, and more
  • Synced live from your PROM Live Google Sheet
  • Search across all realms from one place

One-Click Upload to Drive

Upload any file directly from the extension popup. No manual Drive navigation — the right folder is created automatically.

  • Supports any file type (PDF, PPTX, DOCX, MP4...)
  • Or paste a URL for external links
  • File goes straight into the team's Google Shared Drive

Real-Time Team Sharing

All team members see each other's uploads instantly. Uploader name and timestamp shown on every document card.

  • No manual "Share" steps needed
  • Filter by team member to see who uploaded what
  • Centralized registry via Google Apps Script

Uploader-Only Delete

Only the person who uploaded a file can delete it. This keeps the shared space clean without giving everyone full edit rights.

  • Automatic ownership tracking on every upload
  • Delete button only appears for your own files
  • Files safely removed from both app and Drive

Live PROM Sheet Sync

The customer list stays automatically in sync with your PROM Live Google Sheet — new accounts appear without any manual updates.

  • Pulls Realm ID, Customer Name, Status, Environment Details
  • Syncs on demand with one button click
  • Special Instructions displayed per customer

PSE Resources Tab

A separate admin-protected section for team-wide resources — training docs, quick links, and internal guides not tied to any customer.

  • PIN-protected admin mode (only Krutika can add/delete)
  • Categories, featured resources, and search
  • Quick links for the whole team
Team Collaboration

Everyone sees everything, instantly

When any team member uploads a document, it appears for all 40+ members the next time they open the extension. No email threads with Drive links. No "did you share this with me?" questions.

Every card shows the uploader's name and how long ago it was added — so context is always there.
